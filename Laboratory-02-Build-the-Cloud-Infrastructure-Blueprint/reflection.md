
# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think the most important cloud infrastructure component is the **compute resource** because it provides the processing power needed to run applications, services, and commands. Without sufficient computing resources, other cloud services would not be able to perform their tasks efficiently. Compute resources also allow organizations to adjust their processing capacity depending on their workload.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system environment for cloud servers. During this laboratory activity, I used Linux commands to investigate the operating system, kernel, CPU, RAM, disk, file systems, hostname, and IP address. Its command-line tools make it easier for administrators and cloud engineers to monitor and manage server resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, resources, configurations, and design decisions. Before deployment, documentation helps engineers understand the planned system and identify possible problems. It also makes it easier for team members to maintain, troubleshoot, and improve the infrastructure.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud server using different terminal commands. I also learned how to identify compute, storage, networking, and operating system resources. In addition, I gained experience comparing AWS, Microsoft Azure, and Google Cloud services, creating a basic cloud infrastructure diagram, and writing technical documentation using Markdown.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a complete laboratory project with organized Markdown documentation, server investigation results, cloud provider comparisons, screenshots, and a cloud architecture diagram. This activity also helped me practice organizing files and maintaining a structured repository. Overall, the portfolio now better demonstrates my understanding of basic cloud infrastructure and my ability to document technical work.
